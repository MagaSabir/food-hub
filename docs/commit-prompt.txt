perf     — ускорение
docs     — документация
test     — тесты
chore    — зависимости, конфиги, служебное
ci       — сборка и CI

backend, mobile, admin, auth, catalog, menu, orders, db, seed, config, ci, docs

Не перечисляй файлы. Не пересказывай diff построчно. Не пиши «обновлены
зависимости», если суть изменения в другом. Пиши так, чтобы через полгода
было понятно, ЗАЧЕМ это делалось.
